# Teams 会议助手 使用说明

一个 Chrome / Edge 浏览器插件。用**浏览器版 Teams** 开会时，在右侧侧栏里：

- **实时翻译**：会上每个人说的话，按说话人逐条翻译成中文（或你设定的语言）。
- **总结**：随时一键总结目前讨论了什么、定了什么、谁要做什么。
- **建议回答**：填好你在会上的名字和立场后，别人问到你时会**自动**在那句话下面给出 3 个可以直接念的回答，附中文意思；也可以随时手动点一下生成。
- **帮我说**：用中文写你想表达的意思，生成能直接说出口的外语。
- **会议纪要自动保存**：会议结束时自动生成正式纪要，存成 Markdown 文件。
- **录音**：录下会议声音（可以连你自己的麦克风一起录），和纪要存在一起。
- **背景资料**：把人名、岗位、术语告诉它，翻译和纪要会更准，人名不再被听错。

Windows 和 Mac 都能用。

---

## 一、准备

1. **Chrome 或 Edge 浏览器**（电脑版）。
2. **一个 AI 服务的 API Key**，下面任选一家（翻译、总结、纪要都靠它，按用量付费，见文末「费用」）：

   | 服务商 | 去哪申请 Key | 说明 |
   |---|---|---|
   | Anthropic Claude | console.anthropic.com | 效果最好 |
   | OpenAI（ChatGPT） | platform.openai.com | |
   | Google Gemini | aistudio.google.com | 有免费额度 |
   | DeepSeek 深度求索 | platform.deepseek.com | 便宜，国内直连 |
   | 通义千问（阿里云百炼） | 阿里云百炼控制台 | 国内直连 |
   | Kimi（月之暗面） | platform.moonshot.cn | 国内直连 |
   | 智谱 GLM | open.bigmodel.cn | glm-4-flash 免费 |
   | 豆包（火山方舟） | 火山方舟控制台 | 模型要填控制台里的模型名或接入点 ID |
   | 硅基流动 SiliconFlow | cloud.siliconflow.cn | 一个 Key 用多家开源模型 |
   | OpenRouter | openrouter.ai | 一个 Key 用各家模型 |
   | Ollama | 不用 Key | 在自己电脑上跑模型，免费，但要电脑够强 |
   | 其他 | — | 任何支持 OpenAI 兼容接口的服务，自己填地址 |

   在中国大陆用，DeepSeek、通义千问、Kimi、智谱、豆包、硅基流动不需要翻墙；Claude、OpenAI、Gemini 需要能访问外网。
3. **用浏览器开 Teams 会议**：点会议链接时选「在此浏览器中继续 / Continue on this browser」，不要用 Teams 桌面客户端。网页版地址是 `teams.microsoft.com`。

## 二、安装（只做一次）

1. 解压收到的压缩包，得到 `Teams会议助手` 文件夹。**把它放到一个固定位置**（比如「文档」里），之后别删别挪，插件就是从这个文件夹运行的。
2. 浏览器地址栏打开：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 打开右上角（Edge 在左下角）的 **「开发者模式」** 开关。
4. 点 **「加载已解压的扩展程序」**（Edge 叫「加载解压缩的扩展」），选刚才的 `Teams会议助手` 文件夹。
5. 列表里出现「Teams 会议助手」就装好了。建议点浏览器右上角的拼图图标，把它**固定到工具栏**。
6. 点工具栏上的插件图标，右侧会打开侧栏，第一次会弹出「设置」：
   - **AI 服务商**：选你申请了 Key 的那家，接口地址和常用模型会自动填好；
   - 填 **API Key**；
   - **模型**：一般用默认的就行。想换，点「获取模型列表」后在模型框里选，也可以手动输入；
   - 点 **「测试连接」**，显示「连接正常」就对了；
   - 各家的 Key 会分别记住，以后切换服务商不用重填；
   - **翻译成**：默认简体中文；
   - **我的身份背景**：比如「我是 XX 公司的项目经理，负责 XX」，建议回答会参考；
   - **会议纪要**：选存到哪个文件夹（见第四节）；
   - 想录自己的声音：勾「录音时也录我的麦克风」，再点旁边的「授权一次」。

## 三、每次开会

1. 用浏览器入会。**入会前已经开着的 Teams 页面，装完插件要刷新一次。**
2. **打开 Teams 实时字幕（必须）**：会议工具栏「更多 …」→「语言和语音」→「打开实时字幕」。
   字幕的「口语语言」要设成会议里实际说的语言（比如英语），不然识别会乱。
   本插件不自己听声音，**完全依靠 Teams 的字幕**，没开字幕就没有翻译和纪要。
3. 点工具栏插件图标打开侧栏，字幕会自动出现并翻译。**开会期间别关侧栏**，会议纪要和录音保存都靠它。
4. 想录音：停在 Teams 会议页面，点侧栏左上角「录音」。录会议前请告知参会者。
5. 开完会点 Teams 的「离开」，或直接关掉会议标签页：插件会自动停止录音、生成纪要并保存，然后清空侧栏，给下一场会用。

侧栏四个页面：

| 页面 | 用法 |
|---|---|
| 实时翻译 | 原文 + 译文，按说话人显示 |
| 总结 | 点「生成 / 更新总结」，或勾选每 5 分钟自动更新 |
| 建议回答 | 顶部填「我在 Teams 里的名字」和「我的立场」，勾「有人问我时自动生成」（见下面「自动建议回复」）。也可以手动点按钮生成，框里可以先写这次的想法（比如「想先拒绝」）。下面「帮我说」输入中文、回车 |
| 背景 | 配置背景资料（见第五节） |

**自动建议回复**（推荐打开）

1. 在「建议回答」页顶部填 **我在 Teams 里的名字**：就是字幕里显示你的那个名字（比如 `Li Wei`）。开过会后也可以从「从发言人选…」下拉里直接选。有多个写法用逗号隔开。
2. 填 **我的立场 / 目标**：比如「代表乙方；工期不能再压缩；超出合同的费用要书面确认；不确定的先说回去确认」。每场会可以改。设置里的「我的身份背景」也会一起参考。
3. 勾 **有人问我时自动生成建议回复**。

之后会上有人点了你的名字，或者话里像是在问你（问句、请你更新进度、问你的意见），插件会先判断这句是不是要你回答：要的话，在「实时翻译」里那句话正下方直接出 3 个回答（直接回答 / 先确认再答复 / 委婉推回之类，按场合选），符合你的立场，不知道的数字和日期留成 `[日期]` 让你自己填；「建议回答」页也会同步一份并亮个红点。不需要你回答的（问别人的、只是陈述、你自己说的）不会出。

顶部按钮：**导出** = 现在就生成纪要存一份；**清空** = 清掉本场记录；**设置**。

## 四、纪要和录音存在哪

在「设置 → 会议纪要」里选：

- **存到下载目录里的子文件夹**（默认，最省事）：存在「下载/Teams会议纪要/」，子文件夹名可以改。
- **存到指定文件夹**：点「选择文件夹…」，任意位置都行（比如 Obsidian、OneDrive 文件夹），选的时候点「允许」读写。

文件名像这样，同一场会的放在一起：

```
2026-11-18_1530_周例会.md          ← 会议纪要
2026-11-18_1530_周例会_录音.webm    ← 录音（用 Chrome、VLC 都能播放）
```

纪要内容：时间、发言人、摘要、讨论要点、决定、待办（谁 / 做什么 / 何时）、未决问题、新出现的人员，最后附完整字幕原文和翻译。

> 浏览器重启或插件更新后，文件夹授权会失效，侧栏顶部会出现一条提示，**在侧栏里随便点一下**就会重新授权。
> 没授权就结束了会议也不会丢文件，这次会先存到下载目录。

## 五、背景资料：让它认识你的同事

字幕是语音识别的，人名、公司名、行业术语经常被听错。把这些告诉插件，翻译和纪要会更准，纪要里还会写上「谁 · 什么岗位」。

打开侧栏「背景」页，两种方式可以一起用：

1. **选一个背景资料文件夹（推荐）**：点「选择文件夹…」，选你放人员名单、术语表、项目介绍的文件夹。插件会读里面（含子文件夹）所有 `.md` / `.txt` 文件，页面上列出读到了哪些。每场会开始时自动重读，你在文件夹里改了下次开会就生效；想马上生效点「重新读取」。
2. **直接在下面的框里写**，或者「从文件导入…」。框里的内容只存在这台电脑上。

写法随意，比如：

```
# 人员
John Smith（客户方）— 项目经理
Li Wei — 我方技术负责人

# 术语
SOW — Scope of Work，工作范围
BOQ — Bill of Quantities，工程量清单
```

**会前准备文件**：建议回答也会用背景资料里的内容。开会前把要用到的数据、进度、报价、口径写成一个 `.md` 或 `.txt` 放进背景资料文件夹（文件名带「背景」两个字会优先读，比如 `背景-周三例会准备.md`），别人问到时回答会直接引用里面的事实，口径保持一致。Word、PDF、Excel 读不了，要先把关键内容复制成文字。插件在每场会开始时读取，会前改好就行；会中改了点「重新读取」。

开过一场会后，点「把本场发言人加进来」，会把这场会上出现、资料里还没有的人名列出来，在后面补上岗位就行。纪要末尾的「新出现的人员」也可以抄进资料。

## 六、常见问题

**侧栏一直没有字幕**
- 确认 Teams 里已经打开实时字幕，会议画面底部能看到字幕。
- 刷新一下 Teams 会议页面（会掉线几秒再自动重连）。
- 还是不行，可能是 Teams 网页改版了，联系给你插件的人。

**翻译 / 总结报错**
- 先在「设置」里点「测试连接」，看具体报什么错。
- 「API Key 不对（401/403）」：检查 Key，注意别多复制了空格。
- 「接口地址或模型名不对（404）」：点「获取模型列表」，从里面选一个模型。
- 「429」：额度用完或请求太快，去服务商后台看余额。
- Claude、OpenAI、Gemini 连不上：检查网络能否访问外网，或换一家国内服务商。
- Ollama 报 403：在电脑上设置环境变量 `OLLAMA_ORIGINS=chrome-extension://*` 后重启 Ollama。

**点录音提示「拿不到标签页声音」**
先点一下工具栏的插件图标，再点「录音」（浏览器要求是你亲手触发的）。

**会议结束了没有自动存纪要**
自动保存需要侧栏开着。没自动存的话，侧栏里的字幕还在，点「导出」手动存。

**录音里没有我自己的声音**
设置里勾「录音时也录我的麦克风」，并点「授权一次」。

## 七、费用

字幕用的是 Teams 自带功能，不收费；翻译、总结、纪要调用你选的 AI 服务，按用量付费，钱付给那家服务商。

- 实时翻译会持续调用，一场会的花费主要在这里。长会建议用便宜快速的模型，比如 Claude Haiku / Sonnet、DeepSeek、通义千问 qwen-plus、Gemini Flash、智谱 glm-4-flash（免费）。
- 想省钱又想纪要质量好：平时用便宜模型，重要的会切到贵一点的模型再点「导出」。
- 第一次用可以开一场会，再去服务商后台看看花了多少，心里有数。
- Ollama 在本机运行，完全免费，但翻译质量和速度取决于电脑配置。

## 八、隐私

- API Key、设置、本机背景资料只存在你自己的浏览器里，不会发给别人。
- 字幕内容和背景资料会直接发给你在设置里选的 AI 服务商做翻译和总结，不经过任何其他服务器；选 Ollama 则完全不出你的电脑。
- 录音只存在你的电脑上，不会上传。
- **录会议前请告知参会者**，遵守公司和当地的录音规定。

## 九、更新插件

收到新版本时：解压后用新文件覆盖原来的 `Teams会议助手` 文件夹，然后到 `chrome://extensions`（或 `edge://extensions`）里点这个插件的「重新加载」按钮。设置和资料都会保留，正在开的会也不用刷新。
